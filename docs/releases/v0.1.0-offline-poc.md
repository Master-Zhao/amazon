# Amazon Ads Agent Offline PoC

这是亚马逊广告 Keyword 出价智能体的离线工程 PoC 里程碑。所有验证均使用合成数据、Reasoner Stub、Fake Transport 或 HTTP Mock。

## 已完成

- 单 Keyword 高 ACoS 优化闭环与确定性 Candidate Engine；
- 受控 Reasoner、Schema Validator 和 Runtime Validator；
- 有限自动修订及 `ManualInterventionPackage` 安全停止；
- dry-run Preflight、人工确认边界和零生产写入约束；
- Fake 与 HTTP Mock 测试、12 个固定评估案例；
- GitHub Actions Python 3.12 离线 CI。

## 验证结果

- 本地全量测试：565 passed；
- Fake evaluation：12/12 passed；
- GitHub Actions：`Offline Verification` Run `29796371771` success；
- `real_model_used=false`，真实模型请求数 0；
- `production_write_violation_count=0`。

## 安全边界

- 真实模型质量验证未执行，未配置真实 API Key；
- Amazon Ads API 未接入，无生产 Adapter；
- 没有生产写入；合法方案停在人工确认前；
- Agent revision 与 Transport retry 保持分离，失败路径 fail-closed。

## 已知限制

- 仅覆盖单 Keyword 与合成数据；
- 无前端、数据库或 Approval Service；
- 未实现 Campaign 预算优化、静默学习和真实用户反馈闭环。

## 验证说明

本 Release 是离线工程 PoC 里程碑，不等同于 `poc-02-verified`，也不代表真实模型质量或生产广告系统已经通过验收。
