# V1 明确排除范围

## 1. 外部系统与自动执行

- 不真实调用 Amazon Advertising API。
- 不接入真实第三方广告数据服务商。
- 不直接修改 Amazon 后台广告；审批后只生成人工执行清单。
- 不使用真实大模型密钥；自动化测试和稳定演示使用 MockLLMProvider。

## 2. 业务范围

- 不做跨 Tenant 数据汇总。
- 不直接合计不同 Marketplace 或 currency 的金额。
- 不实现多级复杂审批。
- 不完整实现 Sponsored Brands、Sponsored Display。
- Advertised Product Report 只记录为未来方向，不是 V1 必做报表。
- 不实现完整库存、采购、物流、订单、利润或财务系统。
- 不以物理删除 Campaign、Keyword、Target 作为优化动作。

## 3. AI 与知识

- Agent 不自由聊天、不直接互调、不扩大授权范围、不访问 ORM、不写正式业务状态。
- 不由 LLM 裁决指标、金额、权限、异常规则、状态或执行。
- 不保存或展示模型隐藏思维过程。
- 不实现复杂 RAG、知识图谱、向量平台、自动网络采集或 Agent 自改 Prompt/规则/代码。
- 不把单次用户行为自动升级为团队知识。

## 4. 基础设施与架构

- 不把模块化单体拆为微服务。
- 不引入 Kafka、Kubernetes、Elasticsearch、复杂事件总线或分布式事务框架。
- 不提前设计无证据的分区、分库分表或商业级多地域架构。
- 不把 Redis 作为审批、执行、审计或正式事实的唯一存储。

## 5. 交付表达

- 不用静态页面、空接口、硬编码成功、占位代码或假后台响应冒充链路。
- 不虚构模型效果、广告收益、QPS、并发量、延迟、在线用户数或测试通过状态。
- 不把“接口预留”写成“已实现”。
- 不把虚构/脱敏 fixture 验证写成真实 Amazon 报表验证。

## 6. 当前 Phase 0 额外边界

- 不创建后端或前端业务代码。
- 不创建 Model、业务迁移、接口或页面。
- 不安装项目依赖、不接入外部服务、不配置真实密钥。
- 不开始 Phase 1。
- 不读取、修改、移动、删除或复用 `amazon-ads-operations-0.1.1`。
